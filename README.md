# GAUDICODE 競艇出走表＋予想（表示側・公開）

GitHub Pages で公開する表示専用のリポジトリです。

公開ページ: https://miyanouta.github.io/gaudicode-boat/

- データ（data/*.json）は生成側リポジトリ
  （miyanouta/gaudicode-boat-auto、非公開）から毎朝自動で同期されます。
- 日中は30分ごとに、このリポジトリ自身の Actions が当日のレース結果と
  直前情報（展示タイム等）を取り込んで更新します（深夜0:30に最終取り込み
  を1回追加）。展示が取れたレースは発走前に限り、展示を反映した予想
  （合成スコア = 事前スコア + (−z(展示タイム)) × 2.0、2026-11-14採用）
  へ自動で更新されます（「展示反映」チップ付き）。

予想はスコア方式の自動生成であり、的中・利益を保証するものではありません。
舟券の購入はご自身の判断と責任で行ってください。
